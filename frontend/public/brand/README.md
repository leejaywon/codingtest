# Codingtest brand assets

Acid-green Y2K cyber identity: a faceted crowned C paired with the angular CODINGTEST lettering.

- `codingtest-logo.svg`: current 1120 × 200 horizontal logo used on the website and in the repository README; preserves the original emblem and angular lettering.
- `codingtest-logo.png`: original 960 × 200 horizontal logo, retained as a source asset.
- `codingtest-logo-embedded.svg`: scalable wordmark with an embedded raster emblem; this is not an all-vector logo.
- `codingtest-emblem-source.png`: original transparent 1254 × 1254 generated emblem.
- `codingtest-icon-512.png`: general-purpose square icon.
- `codingtest-icon-180.png`: Apple touch icon.
- `codingtest-icon-32.png` and `codingtest-icon-48.png`: browser favicons.
- `og-image.png`: 1200 × 630 Open Graph / Discord / X / KakaoTalk share preview.

The emblem was created with the built-in image generation tool. Exports were resized with Sharp; the horizontal logo combines that emblem with the existing custom vector lettering. Use a dark background for strongest contrast.

## Generation prompt

Use case: logo-brand. Create a finished standalone square logo symbol for CODINGTEST, a coding practice website. A striking acid-green Y2K cyber emblem: an angular chunky letter C integrated with a three-point crown, a compact unified silhouette, slightly forward leaning, precision-cut broad geometric strokes and generous negative space. Early 2000s futuristic sports technology branding, clean vector-like graphic with restrained lime metallic highlight. Main colors vivid acid green #9ee52b and darker green #5a9a0a. Actual transparent background. Center symbol occupying 88 percent of square, no cast shadow, no outer glow. Must stay clear at favicon size. No text, no wordmark, no mockup, no presentation sheet, no border, no extra ornaments. One production-ready logo only.
